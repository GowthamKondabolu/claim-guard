# Investigator work queue dashboard

**Live application:** [https://gowtham-claimguard.streamlit.app/](https://gowtham-claimguard.streamlit.app/)

ClaimGuard includes an interactive Streamlit dashboard for exploring prioritized healthcare claims and supporting human review. The dashboard presents ensemble rankings and reason codes as review signals—it does not determine fraud, waste, or abuse.

## Capabilities

- Automatically loads a privacy-safe synthetic demonstration queue
- Accepts scored CSV output generated by ClaimGuard
- Filters by claim type, review flag, minimum ensemble score, and reason code
- Displays claim-volume, payment, and review-priority KPIs
- Provides model, rule, and ensemble score analysis
- Supports claim-level drill-down with triggered reason codes
- Exports the currently filtered work queue as CSV
- Includes responsible-use guidance within the interface

## Run locally

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dashboard]"
streamlit run app.py
```

Keep the terminal running and open:

```text
http://localhost:8501
```

Press `Control + C` in the terminal to stop the dashboard.

## Data options

### Synthetic demonstration data

The dashboard generates a privacy-safe demonstration queue automatically. This makes the interface usable without downloading or exposing healthcare data.

### ClaimGuard scored output

Run the training pipeline:

```bash
claimguard train --config configs/base.yaml
```

Then upload this generated file through the dashboard:

```text
data/processed/scored_claims.csv
```

Uploaded data is validated and prepared by `src/claimguard/work_queue.py` before it is displayed.

## Streamlit Community Cloud deployment

After this feature is merged into `main`:

1. Sign in to Streamlit Community Cloud using GitHub.
2. Select the repository `GowthamKondabolu/claim-guard`.
3. Select the `main` branch.
4. Set the application file to `app.py`.
5. Use Python 3.12.
6. Deploy the application.

The root `requirements.txt` installs ClaimGuard with its dashboard dependencies. The application does not require secrets for the synthetic demonstration mode.

## Responsible use

Use only privacy-safe synthetic or appropriately governed data. Do not upload protected health information to a public deployment. Scores, flags, and reason codes are prioritization signals for qualified human reviewers and must not be interpreted as proof of fraud or used to make automated payment or clinical decisions.
